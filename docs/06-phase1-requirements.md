## 3. Phase 1 완료 조건

1. `npm run check` 통과 (계약 + 단위 + 통합)
2. Fake Device → Fake Mobile → API → Fake AI → Conversation 조회/검색 전 구간 통과
3. 전송 중단 → 재개 시나리오 통과 (바이트 무손실, 해시 일치)
4. `stored` 이전 삭제 요청이 거부되는 테스트 존재
5. 마이그레이션을 빈 DB 에 적용해 스키마가 재현됨
6. 실제 하드웨어·iPhone 항목은 `HW-PENDING` 으로 분리 (완료 표기 금지)
